# Marketplace Operations Analytics

BI-проект по анализу заказов, товарных категорий и операционных показателей бразильского маркетплейса на основе открытого датасета Olist.

## Цель проекта

Построить аналитический отчёт, который помогает изучать динамику заказов, распределение заказов по статусам и категории товаров с наибольшей суммой стоимости товарных позиций.

## Стек технологий

- **PostgreSQL** — хранение данных и SQL-анализ.
- **Python** — подключение к базе данных и загрузка CSV.
- **Pandas** — первичное исследование данных.
- **Power BI Desktop** — визуализация и интерактивный отчёт.
- **Git** — контроль версий проекта.

## Источник данных

Brazilian E-Commerce Public Dataset by Olist.

[Открыть датасет на Kaggle](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)

Датасет содержит сведения о заказах, покупателях, продавцах, товарах, платежах и отзывах.

## Что сделано

### 1. Подготовка данных
- Создана база данных PostgreSQL `marketplace_analytics`.
- Созданы таблицы в схеме `raw`.
- Разработан Python-скрипт для загрузки CSV в PostgreSQL.
- Загружено 550 759 строк в 8 таблиц.

### 2. Проверка качества данных
- Проверены связи между заказами, покупателями, товарами, продавцами, платежами и отзывами.
- Проверены оценки покупателей, суммы и порядок дат.
- Обнаружены 8 доставленных заказов без фактической даты получения.
- Результаты и ограничения данных описаны в документации.

### 3. SQL-анализ
- Количество заказов по месяцам.
- Распределение заказов по статусам.
- Топ-10 категорий по сумме стоимости товарных позиций.

### 4. Дашборд Power BI
Отчёт включает:
- общее количество заказов;
- динамику заказов по месяцам;
- топ-10 категорий по сумме стоимости товарных позиций;
- распределение заказов по статусам.

Для сопоставимости визуализаций в отчёте установлен фильтр по дате оформления заказа до 1 сентября 2018 года.

## Запуск проекта

1. Установить PostgreSQL и Python.
2. Создать базу `marketplace_analytics`.
3. Выполнить `sql/01_schema.sql` в Query Tool PostgreSQL.
4. Установить необходимые библиотеки Python.
5. Создать локальный файл `.env` с параметрами подключения к PostgreSQL.
6. Поместить исходные CSV в `data/raw/`.
7. Выполнить `python .\load_data.py`.
8. Выполнить SQL-проверки и аналитические запросы из папки `sql/`.
9. Открыть `powerbi/marketplace_analytics.pbix` в Power BI Desktop.
