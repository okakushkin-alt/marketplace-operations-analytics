# Marketplace Operations Analytics

BI-проект для анализа продаж, доставки и эффективности продавцов маркетплейса.

## Стек
- PostgreSQL
- SQL
- Python / Pandas
- Power BI

## Источник данных
Brazilian E-Commerce Public Dataset by Olist:
https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

## Цели проекта
- Анализ динамики заказов и товарной выручки.
- Оценка своевременности доставки.
- Исследование связи доставки с отзывами покупателей.
- Анализ эффективности продавцов и категорий товаров.

## Статус
Этап 1 — подготовка окружения.
