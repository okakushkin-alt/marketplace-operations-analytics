# Первичные результаты анализа качества данных

## Источник
Brazilian E-Commerce Public Dataset by Olist.

## Результаты проверок

- Загружено 550 759 строк в 8 таблиц.
- Проверки связей между заказами, покупателями,
  товарами, продавцами, платежами и отзывами
  не выявили несвязанных записей.
- Проверки сумм, оценок и порядка дат не выявили
  проблем по использованным критериям.
- Найдено 8 заказов со статусом delivered,
  но без фактической даты получения покупателем.

## Ограничения

Для 8 заказов нельзя определить фактическую
длительность доставки и своевременность.
Их необходимо учитывать отдельно при расчёте KPI.

Исходные данные не изменялись.
